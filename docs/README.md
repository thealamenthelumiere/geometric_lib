# Geometric Library

## Общее описание решения

Geometric Library - это Python-библиотека для вычисления площадей и периметров геометрических фигур. 
Проект предоставляет простой интерфейс для математических операций с фигурами.

### Поддерживаемые фигуры:
- Прямоугольник
- Треугольник

## Описание функций

### Модуль rectangle.py

#### area(a, b)
Вычисляет площадь прямоугольника.

**Параметры:**
- `a` (float): Длина первой стороны
- `b` (float): Длина второй стороны

**Возвращает:**
- float: Площадь прямоугольника

**Пример:**
```python
result = area(5, 3)  # 15.0
